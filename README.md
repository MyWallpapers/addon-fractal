# Infinite

Explorer une fractale de Mandelbrot : centre, zoom, précision et palette. Rendu statique, sans animation permanente.

Aucun réseau, accès natif, collecte ou service privé du cœur. Le calcul est plafonné à une grille de 320×320 pixels et 160 itérations ; les modifications sont regroupées sur une frame, puis aucun calcul permanent ne reste actif.

Installez avec `pnpm install`, compilez avec `pnpm build`, vérifiez avec `pnpm test`, puis utilisez `mywallpaper dev` pour appairer le projet à MyWallpaper. Après `mywallpaper check`, poussez ce dépôt public avec un tag immuable de même version que le manifeste et publiez depuis l’application.
